# Emergency Response AI Command Centre

AINL3001 Knowledge-Driven AI group project by **The A-Team**.

A simulated city dispatch assistant that prioritises incidents with rule-based reasoning, assigns responders using constraint satisfaction, plans routes with A\* search and explains its decisions.
